# v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Odd units and paper, real bank rules (no stacking + exclusions), mini-cart prices, clearer product card, and an audit loop over all categories.

**Spec:** `docs/superpowers/specs/2026-11-09-v3-unidades-bancos-tarjeta-design.md`

## Global Constraints

- Label shape exactly as the spec: `{ group, value, drained, take, note, bankValue, bankName, bankBlocked }`.
- Groups: `kg | L | unidad | m2 | m | rollo10m | panos100 | sin_dato`. Unit text: `kg`, `L`, `unidad`, `m²`, `m`, `10 m`, `100 paños`.
- Copy verbatim: `Precio real para comparar`; `Banco no aplica: ya está en oferta`; `Banco no aplica: excluido de promos`; `Más barato por <u>`; mini-cart `$<n> con promo`, `Con promos: $<n>`, `<Día> con <Banco>: $<n>`.
- Never remove Coto nodes; only add nodes and `data-coto-unit-*` attributes.

## Review Focus

1. Paper names without meters ("FELPITA Doble Hoja Paquete 4 Unidades") → fall back to m² with note `doble hoja`. Test in Task 1.
2. Weighable product with `formatPrice` empty → kg = listPrice (with offer applied). Test in Task 1.
3. Product in an excluded category but also on sale → `bankBlocked: "oferta"` (offer reason wins). Test in Task 2.
4. Mini-cart opened on a non-cart page with no cached cart body → nothing shown, no errors. Test in Task 5.
5. Card without offer (no `.descuentos-slot`) → box goes after `h4.card-title`. Test in Task 4.
